# Markdown to HTML Converter

## Description

A simple Markdown to HTML Converter built with HTML, CSS, and JavaScript. It allows users to write Markdown syntax and instantly see the converted HTML code alongside a live preview.

This project was built to practise JavaScript, regular expressions, string manipulation, and DOM manipulation.

## Features

- Convert headings (`#`, `##`, `###`) into HTML heading elements.
- Convert bold and italic text into HTML formatting elements.
- Convert images and links into HTML elements.
- Convert blockquotes into HTML blockquote elements.
- Convert unordered and ordered lists into HTML lists.
- Support inline code using backticks.
- Protect inline code snippets from being affected by other Markdown formatting rules.
- Display the generated HTML code and a live preview as the user types.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## How to Use

1. Open the Markdown Converter.
2. Enter your Markdown syntax in the input area.
3. View the generated HTML in the Raw HTML Output section.
4. See how the converted content looks in the HTML Preview section.

## What I Learned

While building this project, I practised:

- Using regular expressions to identify Markdown syntax.
- Using JavaScript string methods such as `match()` and `replace()`.
- Working with arrays and the `map()` and `forEach()` methods.
- Using placeholders to temporarily protect inline code snippets during text conversion.
- Updating the DOM dynamically using JavaScript event listeners.

## Note

This is a beginner-friendly Markdown converter that supports selected Markdown syntax. It is not intended to implement the complete Markdown specification.
